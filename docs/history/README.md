# Historische Dokumentation

Die Unterordner enthalten eingefrorene Feature-Notizen, Abschlussberichte und Audits aus früheren Arbeitspaketen. Sie werden für Nachvollziehbarkeit aufbewahrt, aber nicht laufend auf Richtigkeit geprüft.

Für Entscheidungen und Implementierungen ausschließlich die Referenzen außerhalb von `docs/history/` verwenden. Bei einem historischen Dokument ist sein Pfad bzw. sein im Text genannter Stichtag maßgeblich, nicht das heutige Systemverhalten.
